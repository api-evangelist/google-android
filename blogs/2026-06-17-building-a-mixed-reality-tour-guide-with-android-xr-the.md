Developers can now combine the Geospatial API preview in ARCore for Jetpack XR with Gemini and Firebase AI Logic to create world-scale spatial experiences. The post demonstrates building an immersive tour guide using VPS positioning, LLM-generated itineraries, text-to-speech narration, and 3D rendering with Jetpack Compose for XR.
